# 🎮 Python Tic-Tac-Toe

A simple two-player Tic-Tac-Toe game built using Python.

## 📌 Features

- Two-player gameplay (X and O)
- 3×3 game board
- Player turn switching
- Position validation
- Prevents players from choosing occupied positions
- Automatic win detection
- Draw detection
- Displays the updated board after every move

## 🛠️ Concepts Used

- Variables
- Nested Lists
- While Loops
- For Loops
- If-Else Statements
- Logical Operators (`and`, `or`)
- Break and Continue
- Input Handling

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```
